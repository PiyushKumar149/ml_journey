## 📝 What I Learned

Today I built my first machine learning classification project: **Rock vs Mine Prediction** using the **Sonar Dataset**.

The objective of this project is to classify whether an object detected by sonar signals is a **Rock (R)** or a **Mine (M)** based on the reflected sonar signal data.

I learned how to load and explore the dataset using Pandas, separate the input features and target labels, and split the data into training and testing sets.

I trained a **Logistic Regression** model using Scikit-learn and evaluated its performance using the **Accuracy Score** on both the training and testing datasets.

Finally, I built a prediction system that accepts new sonar readings as input and predicts whether the object is a **Rock** or a **Mine**.
