## 📖 Overview

Today, I implemented the **Linear Regression algorithm from scratch** using Python and NumPy without relying on Scikit-learn's `LinearRegression` class. The goal was to understand the mathematical foundation of the algorithm and how it learns the relationship between input features and target values.

## 📚 Topics Covered

* Building the prediction equation
* Calculating Mean Squared Error (MSE)
* Visualizing the best-fit regression line using Matplotlib

---

## 🧠 Key Concepts Learned

### Linear Regression Equation

[
y = mx + b
]

Where:

* **m** = Slope (Weight)
* **b** = Intercept (Bias)
* **x** = Input Feature
* **y** = Predicted Output

### Steps Followed

1. Loaded the dataset.
2. Calculated the mean of X and Y.
3. Computed the slope using the mathematical formula.
4. Calculated the intercept.
5. Predicted output values.
6. Evaluated the model using Mean Squared Error (MSE).
7. Plotted the regression line with the original data.
