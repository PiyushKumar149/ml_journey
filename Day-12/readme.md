## 📝 What I Learned

Today I learned **Support Vector Machine (SVM)**, a powerful supervised machine learning algorithm primarily used for **classification problems**. SVM works by finding the optimal hyperplane that separates different classes while maximizing the margin between them.

I understood the concepts of **hyperplanes**, **support vectors**, and **maximum margin**, which are the core ideas behind SVM. I also learned how SVM handles data that is not linearly separable using the **Kernel Trick**, allowing it to create non-linear decision boundaries.

Additionally, I explored different kernel functions such as **Linear**, **Polynomial**, and **Radial Basis Function (RBF)** kernels, and learned the importance of the **regularization parameter (C)** in controlling the trade-off between maximizing the margin and minimizing classification errors.

Finally, I implemented a **Linear Support Vector Machine from scratch using NumPy**, including weight initialization, parameter updates using gradient descent, training the model, and making predictions on unseen data.
