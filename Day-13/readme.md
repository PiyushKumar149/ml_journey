## 📝 What I Learned

Today I built a **Diabetes Prediction** machine learning project using the **Support Vector Machine (SVM)** algorithm.

The objective of this project is to predict whether a person is **diabetic or non-diabetic** based on medical attributes such as glucose level, blood pressure, BMI, insulin level, age, and other health-related features.

I learned how to load and analyze the dataset, separate the input features from the target variable, and preprocess the data for model training. Since SVM is sensitive to feature scales, I applied **StandardScaler** to standardize all the features before training the model.

After preprocessing, I split the dataset into training and testing sets and trained an **SVM classifier** using Scikit-learn. I evaluated the model using the **Accuracy Score** on both the training and testing datasets.

Finally, I built a prediction system that accepts new patient data as input and predicts whether the person is diabetic or not.
